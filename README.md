## How to run

1. Install Python 3.
2. Download or clone the LoanLens repository.
3. Open the project folder in VS Code or a terminal.
4. Run the following command:

```bash
python main.py
```

## Features that work

1. Calculate monthly EMI using loan principal, annual interest rate and tenure in months.
2. Generate a complete monthly amortisation schedule showing EMI, interest, principal and outstanding balance.
3. Compare up to three loan offers and identify the offer with the lowest total interest.
4. Calculate the effect of a one-time prepayment on the remaining loan tenure and interest.
5. Validate user inputs and reject invalid loan details.
